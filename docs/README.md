1. 점심 메뉴 추천 인트로 출력
2. 코치 이름 입력
   * , 로 구분 
   * 최소 2글자, 최대 4글자
   * 코치는 최소 2명, 최대 5명
   * 잘못된 입력시 예외 후 재입력
3. 코치 별 못먹는 음식 입력
   * , 로 구분
   * 최소 0개, 최대 2개
   * 0개는 빈 값
   * 추천을 못하는 경우 없음
   * 잘못된 입력시 예외 후 재입력
4. 메뉴 추천
   * 각 요일에 대해 카테고리를 무작위로 정한다.
     * 한 주에 같은 카테고리는 최대 2개
   * 각 코치가 월요일에 먹을 메뉴를 추천한다.
     * 매일 다른 메뉴를 먹어야 한다.

카테고리
* Randoms.pickNumberInRange() 활용
* 1이면 일식, 2면 한식, 3이면 중식, 4면 아시안, 5면 양식

메뉴
* Randoms.shuffle() 활용 - 첫 번째 값 사용
